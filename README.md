# Academic Homepage

This repository contains the source files for a Quarto-based academic homepage.

Draft site URL after GitHub Pages is enabled:

```text
https://dululu29.github.io/
```

## Local preview

Install Quarto, then run:

```bash
quarto preview
```

## Render locally

```bash
quarto render
```

## Notes

- The repository can stay private while drafting.
- Do not enable GitHub Pages until the public-facing content is ready.
- Before publishing, confirm the display name, affiliation, email address, CV file, Google Scholar, ORCID, and publication list.
